## 10. 关键决策点回顾

### 10.1 关键决策点 1：5 级状态机（13 个状态）

```
draft → self_submitted → manager_scoring → manager_scored
  → dept_calibrating → dept_calibrated → hr_summarizing → hr_summarized
  → ceo_approving → ceo_approved → archived
```

5 个流转点调 `approval.submitApproval(flowKey=...)`：
- self_submitted → manager_scoring：`performance:self_submit`
- manager_scored → dept_calibrating：`performance:manager_score`
- dept_calibrated → hr_summarizing：`performance:dept_calibrate`
- hr_summarized → ceo_approving：`performance:hr_summary`
