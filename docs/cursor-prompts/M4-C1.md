## 4. 实施任务

### 4.1 子任务 1.1：薪级定义（salary_grades）

**表**：`salary_grades`
- 字段：id (uuid) / sequence (enum) / gradeCode (string) / name (string) / minBaseSalary (decimal) / maxBaseSalary (decimal) / minPerformanceBase (decimal) / maxPerformanceBase (decimal) / status (enum) / createdById (uuid FK) / createdAt / updatedAt
- enum：`sequence` ∈ {`M`, `T`, `P`, `S`, `A`}（M=executive+manager, T=tech, P=production, S=sales, A=admin/function）；`status` ∈ {`active`, `archived`}
- 约束：`@@unique([sequence, gradeCode])`（同序列 gradeCode 唯一）+ min < max
- index：`@@index([sequence, status])`

**Service 函数**：
- `createGrade(actorId, input)` — 创建薪级（sequence 白名单 + range 校验 + unique 校验）
- `listGrades(actorId, filter)` — 列表（sequence/status 过滤）
- `updateGrade(actorId, id, input)` — 更新（仅 active 可改 range + name，sequence + gradeCode 不可改）
- `archiveGrade(actorId, id)` — 归档（active → archived，需无 active level 关联）

**Controller 函数**：
- `POST /salary/grades` → 调 createGrade
- `GET /salary/grades` → 调 listGrades

**完整 schema + JSDoc + 错误码触发条件 + 测试断言**：见 §5.1。

### 4.2 子任务 1.2：薪档定义（salary_grade_levels）

**表**：`salary_grade_levels`
- 字段：id (uuid) / gradeId (uuid FK) / level (int 1-7) / baseSalary (decimal) / performanceBase (decimal) / status (enum) / createdById (uuid FK) / createdAt / updatedAt
- enum：`status` ∈ {`active`, `archived`}
- 约束：`@@unique([gradeId, level])`（同 gradeId 同一 level 唯一）；level ∈ [1, configs.salary.grade.levels_per_grade]（默认 1-6）
- 校验：baseSalary ∈ [grade.minBaseSalary, grade.maxBaseSalary]（73007）；同 grade 下 level 递增（73008）
- index：`@@unique([gradeId, level])` + `@@index([gradeId, level, status])`

**Service 函数**：
- `createLevel(actorId, input)` — 创建薪档（range 校验 + 递增校验 + unique 校验）
- `listLevels(actorId, filter)` — 列表（gradeId/status 过滤）
- `updateLevel(actorId, id, input)` — 更新（仅 active 可改 baseSalary + performanceBase，level 不可改）
- `archiveLevel(actorId, id)` — 归档（active → archived）

**Controller 函数**：
- `POST /salary/grade-levels` → 调 createLevel
- `GET /salary/grade-levels` → 调 listLevels

**完整 schema + JSDoc + 错误码触发条件 + 测试断言**：见 §5.2。

### 4.3 子任务 1.3：员工薪酬方案（employee_salary_plans）

**表**：`employee_salary_plans`
- 字段：id (uuid) / employeeId (uuid FK) / gradeId (uuid FK) / levelId (uuid FK) / baseSalary (decimal) / performanceBase (decimal) / allowance (decimal nullable) / welfare (text nullable) / effectiveFrom (date) / effectiveTo (date nullable) / status (enum) / createdById (uuid FK) / createdAt / updatedAt
- enum：`status` ∈ {`active`, `inactive`, `superseded`}（superseded = 被新方案覆盖）
- 约束：`baseSalary >= level.baseSalary`（不低于当前档位）
- 同一 employee 同一时间只能有 1 条 active plan
- index：`@@index([employeeId, status])` + `@@index([employeeId, effectiveFrom, effectiveTo])` + `@@index([status, effectiveTo])`

**Service 函数**：
- `createPlan(actorId, input)` — 创建薪酬方案（effectiveFrom 默认次月 1 日 + 校验 employee 存在 + 校验 level 有效 + **不写** employee_salary_history）
- `listPlans(actorId, filter)` — 列表（employeeId/status/effectiveFrom 过滤 + 分页 + 权限过滤）
