# M5-05 Fix 2：processor 路径解析 + 沙箱红线强化

> **关联任务**：M5-05 并发压测
> **Fix 轮次**：fix2（第 2 次修订）
> **根因**：
> 1. artillery `processor: "./processor.mjs"` 按**运行时的 CWD** 解析，而非 yml 文件所在目录；`pnpm test:load` 的 CWD 是项目根目录，导致 processor 文件找不到，beforeScenario 未执行，token 注入失败（401）
> 2. 调试时误用 `/tmp/` 目录触发沙箱拒绝，任务被中止

---

## 上一轮状态

- `loadtest/processor.mjs` — 逻辑正确（fs.readFileSync + JSON.parse）
- `loadtest/auth-setup.mjs` — 逻辑正确（token 复用 + `{token, exp}` 落盘）
- `loadtest/load-test.yml` — 内容正确，但 `processor: "./processor.mjs"` 路径解析错误
- `loadtest/test-smoke.yml` — 同上
- `package.json` 的 `test:load` — 未 cd 进 loadtest/ 目录

## 修复要求

### 1. 修复 processor 路径解析（最关键）

artillery 的 `processor` 路径按**运行命令时的 CWD** 解析，不是按 yml 文件位置解析。

**修改 `package.json` 的 `test:load` script**：

```json
"test:load": "cd loadtest && node auth-setup.mjs && artillery run load-test.yml"
```

这样 CWD 变为 `loadtest/`，`processor: "./processor.mjs"` 正确指向 `loadtest/processor.mjs`。

**同时修改 `loadtest/load-test.yml` 的 processor 路径为明确相对路径**：

```yaml
config:
  processor: "./processor.mjs"
```

（保持 `./processor.mjs` 即可，因为 cd 进 loadtest 后 CWD 正确）

### 2. 删除 test-smoke.yml（上一轮遗留，无需保留）

`loadtest/test-smoke.yml` 是上一轮调试产物，直接删除。若需要 smoke 验证，用 `load-test.yml` 的 warm-up 阶段（30s/5VU）即可，或临时写一个 `loadtest/tmp/smoke.yml`（tmp/ 已在 .gitignore）。

### 3. 沙箱红线再强化（防止再次触发 external_directory 拒绝）

**严禁使用 `/tmp/` 或任何工作区外路径**。所有调试脚本、临时文件、probe 文件**必须**写在：
- `loadtest/tmp/`（已在 .gitignore）
- 或 `loadtest/` 内其他子目录

**允许命令白名单**（调试时只从这些命令中选）：
- `node` / `pnpm` / `pnpm exec artillery` / `npx artillery`
- `curl`（不落文件到工作区外）
- `cat` / `ls` / `grep`
- `cd` / `rm`

**严禁**：
- `cat > /tmp/...` / 任何 `/tmp` 路径
- `python` / `python3`
- 读取 `.env`

### 4. 验证步骤（必须在报告前全部完成）

1. 修改 `package.json` 的 `test:load` script
2. 删除 `loadtest/test-smoke.yml`
3. 运行 `pnpm test:load`（完整 4 分钟压测）
4. 若首次 token 注入仍有问题，**只许**在 `loadtest/tmp/` 下放调试脚本，用 `node loadtest/tmp/debug.mjs` 运行排查
5. 达标判定：100VU 保持阶段错误率 <1%，各场景 p95 <2000ms
6. token 复用验证：15 分钟内第二次跑 `pnpm test:load` 应显示「复用已有 token」

### 5. 其他文件保持不变

- `loadtest/processor.mjs` — 不用改，逻辑已正确
- `loadtest/auth-setup.mjs` — 不用改，逻辑已正确
- `loadtest/load-test.yml` — 仅确认 processor 路径，内容不动
- `loadtest/README.md` — 不动
