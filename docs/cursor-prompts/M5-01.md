## 2. 上下文

### 2.1 项目位置

- 项目根：`D:\projects\hrms`；契约文件：`docs/openapi.yaml`；已有 `docs/api-spec.md`（仅供参考，不必读）

### 2.2 openapi.yaml 结构样例（行解析依据）

```yaml
  /auth/login:
    post:
      tags: [Auth]
      summary: 用户登录
      security: []
      requestBody:
        required: true
        ...
```

- 路径行：`^  (/\S+):$`（两空格）
- 方法行：`^    (get|post|patch|put|delete):$`（四空格）
- 操作属性（六空格）：`tags: [X]`（取第一个 tag 作目录名）、`summary: 文本`、`security: []`（= 公开端点）、`requestBody:`（= 需要请求体占位）
- 路径参数形如 `{id}`，集合中转为 `:id` 并填入 `url.variable`

### 2.3 Postman Collection v2.1 关键结构

- `info.schema = "https://schema.getpostman.com/json/collection/v2.1.0/collection.json"`
- 目录 = `item` 数组里的 folder（含嵌套 `item`）
- 请求：`{ name, request: { method, url: { raw, host: ["{{baseUrl}}"], path: [...], variable: [...] }, auth?, body? }, event? }`
- 集合级 auth：`{ auth: { type: "bearer", bearer: [{ key: "token", value: "{{accessToken}}", type: "string" }] } }`；公开端点在请求级覆盖为 `{ type: "noauth" }`
- 登录请求挂 `event: [{ listen: "test", script: { exec: [...] } }]`：从响应提取 token 写入集合变量：
  `pm.collectionVariables.set("accessToken", pm.response.json().data.accessToken)`（refreshToken 同理；refresh 请求同样处理）
- 集合变量：`variable: [{ key: "accessToken", value: "" }, { key: "refreshToken", value: "" }]`

## 4. 实施任务

### 4.1 `scripts/build-postman-collection.mjs`（新增，零依赖）

行解析 `docs/openapi.yaml` → 生成 §2.3 规范的集合：

1. 按 §2.2 规则提取 185 个操作（路径 + 方法 + tag + summary + 是否公开 + 是否有 requestBody）
2. 组目录（tag → folder，无 tag → `其他`）
3. 每条请求：name = summary（缺失则 `METHOD /path`）；url.host = `["{{baseUrl}}"]`、path 段拆分、`{param}` → `:param` 且填入 `url.variable`（value 留空）
4. requestBody 存在 → `body: { mode: "raw", raw: "{\n\n}", options: { raw: { language: "json" } } }`
5. 公开端点（security: []）→ 请求级 `auth: { type: "noauth" }`；其余继承集合级 bearer
6. `/auth/login` 与 `/auth/refresh` 请求挂 token 提取 test 脚本（§2.3）
7. 输出到 `postman/hrms-api.postman_collection.json`（自动创建目录），末尾打印统计：`Generated N requests in M folders → postman/hrms-api.postman_collection.json`
8. **运行它**生成集合（允许且必须）
