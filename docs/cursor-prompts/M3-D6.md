**调薪算法**（V1.2 §二.5.5 调薪规则）：

```ts
// 1. 查 employee 近 4 季度 performance_records（status='archived'）
// 2. 统计 4 季度 finalGrade 分布
const totalRecords = records.length;  // 应 = 4
const sCount = records.filter(r => r.finalGrade === 'S').length;
const aCount = records.filter(r => r.finalGrade === 'A').length;
const sRatio = sCount / totalRecords;
const aRatio = aCount / totalRecords;

// 3. 调薪判定
let adjustmentRate = 0;
if (sRatio > configs.performance.salary_adjustment.s_threshold) {  // > 0.5
  adjustmentRate = configs.performance.salary_adjustment.s_adjustment;  // 0.1 = 10%
} else if (aRatio > configs.performance.salary_adjustment.s_threshold) {
  adjustmentRate = configs.performance.salary_adjustment.a_adjustment;  // 0.05 = 5%
}

// 4. 写 audit（detail 含 sRatio, aRatio, adjustmentRate, evaluationQuarters）
// 注：D6 提议 = 写 audit；D6 审批 = 写 audit；**实际写入 employee_salary_history 留 M4 联调**
```
