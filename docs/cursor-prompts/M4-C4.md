**V1.2 §二.4.2 月度核算公式**：

```
应发工资 = 基本工资
        + 绩效工资（绩效工资基数 × 绩效系数）
        + 保密补贴（固定，按职级）
        + 勤补贴（按出勤天数 × 标准）
        + 项目奖金（按项目触发）
        + 销售提成（按回款金额 × 提成比例，D5 联动）
        + 年终奖（12 月单独发放，C3 算法）
        + 差旅补助（出差天数 × 标准，B5 联动）
        + 加班费（加班时长 × 加班费标准，B4 联动）

应扣款项 = 社保（个人部分，C2 算法）
        + 公积金（个人部分，C2 算法）
        + 个税（累计预扣，C3 算法）
        + 事假扣款（事假天数 × 日工资，B3 联动）
        + 病假扣款（病假天数 × 日工资 × 20%，B3 联动）
        + 迟到早退扣款（按次 × 标准，B2 联动）

实发工资 = 应发工资 - 应扣款项
```

**V1.2 §二.4.2 AI 算薪校验摘要**：

### 3.7 算薪引擎算法（V1.2 §二.4.2 完整公式）

```ts
// 应发工资
const grossAmount = 
    baseAmount                                      // 基本工资（C1 employee_salary_plans.baseSalary）
  + performanceAmount                              // 绩效工资（C1 performanceBase × D3 绩效系数）
  + overtimeAmount                                  // 加班费（B4 overtime_requests）
  + allowanceAmount                                 // 保密补贴 + 勤补贴 + 项目奖金 + 差旅补助（B5）
  + salesCommissionAmount                           // 销售提成（D5 联动，留独立任务）
  + yearEndBonusAmount;                            // 年终奖（C3 算法，12 月单独）

// 应扣款项
const deductionAmount =
    socialInsuranceAmount                           // 社保个人部分（C2 social_insurance_schemes）
  + housingFundAmount                               // 公积金个人部分（C2 housing_fund_schemes）
  + taxAmount                                       // 个税（C3 tax_calculation.service）
  + absenceAmount;                                  // 考勤扣款（B3 leave_requests + B2 attendance_records）

// 实发工资
const netAmount = grossAmount - deductionAmount;

// 异常检测（V1.2 §二.4.2 末尾）
if (anomaly检测 = true) {
  // 绝对差 > 1000 元 或 比例 > 10%
  // 写 audit + 提示 HR 解决
}
```

### 10.1 关键决策点 1：C4 是 M4 核心切片（算薪引擎 + 流程 + AI 集成）
