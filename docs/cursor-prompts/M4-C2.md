## 4. 实施任务

### 4.1 子任务 2.1：三地社保方案配置（social_insurance_schemes）

**表**：`social_insurance_schemes`
- 字段：id (uuid) / city (enum) / insuranceType (enum) / companyRate (decimal) / personalRate (decimal) / baseMin (decimal) / baseMax (decimal) / baseAdjustmentMonth (int) / status (enum) / createdById (uuid FK) / createdAt / updatedAt
- enum：`city` ∈ {`xi_an`, `bei_jing`, `si_chuan`}；`insuranceType` ∈ {`pension`, `medical`, `unemployment`, `work_injury`, `maternity`}；`status` ∈ {`active`, `archived`}
- 约束：`@@unique([city, insuranceType])`（同 city+insuranceType 唯一）
- index：`@@unique([city, insuranceType])` + `@@index([city, status])` + `@@index([insuranceType, status])`

**Service 函数**：
- `createScheme(actorId, input)` — 创建方案（city 白名单 + insuranceType 白名单 + rate 范围 + baseMin < baseMax + unique 校验）
- `listSchemes(actorId, filter)` — 列表（city/insuranceType/status 过滤 + 分页）
- `updateScheme(actorId, id, input)` — 更新（仅 active 可改 rate/base；city+insuranceType 不可改）
- `archiveScheme(actorId, id)` — 归档（active → archived，需无 active registration 关联）

**Controller 函数**：
- `POST /salary/insurances/social` → 调 createScheme
- `GET /salary/insurances/social` → 调 listSchemes
- `PATCH /salary/insurances/social/:id` → 调 updateScheme

**完整 schema + JSDoc + 错误码触发条件 + 测试断言**：见 §5.1。

### 4.2 子任务 2.2：三地公积金方案配置（housing_fund_schemes）

**表**：`housing_fund_schemes`
- 字段：id (uuid) / city (enum) / companyRate (decimal) / personalRate (decimal) / baseMin (decimal) / baseMax (decimal) / status (enum) / createdById (uuid FK) / createdAt / updatedAt
- enum：`city` ∈ {`xi_an`, `bei_jing`, `si_chuan`}；`status` ∈ {`active`, `archived`}
- 约束：`@@unique([city])`（同 city 唯一）；rate ∈ [0.05, 0.12]（V1.2 §二.4.3）
- index：`@@unique([city])` + `@@index([city, status])`

**Service 函数**：
- `createFund(actorId, input)` — 创建方案（city 白名单 + 5%-12% 校验 + unique 校验）
- `listFunds(actorId, filter)` — 列表（city/status 过滤 + 分页）
- `updateFund(actorId, id, input)` — 更新（仅 active 可改 rate/base；city 不可改）
- `archiveFund(actorId, id)` — 归档（active → archived，需无 active registration 关联）

**Controller 函数**：
- `POST /salary/insurances/housing-fund` → 调 createFund
