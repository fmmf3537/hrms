### 4.3 子任务 4.3：部门池模式计算

**Service 函数**（部门池模式）：
- `calculatePool(actorId, input)` — 部门池批量计算（按 deptId + cycleId + month）
- `calculatePoolByDept(actorId, deptId, cycleId, month)` — 单部门池计算

**部门池计算公式**（V1.2 §二.5.3）：
```ts
// 步骤 1：计算每个部门成员的"基础分配额"
deptPool = sum(employee.basePerformanceSalary) × deptCoefficient

// 步骤 2：按个人系数 / 部门成员系数总和 二次分配
for each member in dept:
  memberCoefficientSum = sum(member.coefficient)  // 个人 S/A/B/C/D 系数
  memberAmount = deptPool × (memberCoefficientSum / deptMemberCoefficientSum)

// 注：deptCoefficient 默认 1.0（configs.performance.payout.dept_coefficient_default）
// 部门池最小成员数 ≥ configs.performance.payout.pool.min_members（默认 5）
```

**Controller 函数**：
- `POST /payouts/calculate-pool`（body 含 deptId + cycleId + month）→ 调 calculatePoolByDept
- `POST /payouts/calculate`（body 含 mode=pool）→ 调 calculatePool

**完整 schema + JSDoc + 错误码触发条件 + 测试断言**：见 §5.3。

### 4.4 子任务 4.4：预支 + 清算

**Service 函数**：
- `prepay(actorId, input)` — 预支（季度前 2 月按 1.0 系数预支 50% 基数）

**预支算法**（V1.2 §二.5.3）：
```ts

## 10. 关键决策点回顾

### 10.1 关键决策点 1：双轨制公式（V1.2 §二.5.3）

```
模式一（直乘，默认）：
  绩效工资 = 绩效工资基数 × 绩效系数
  D 档 actualAmount = 0（configs.performance.payout.direct.excluded_grades）

模式二（部门池）：
  部门绩效池 = sum(部门成员 basePerformanceSalary) × deptCoefficient
  个人绩效工资 = 部门绩效池 × (个人系数 / 部门成员系数总和)
```

D4 仅实现 direct + pool，hybrid 模式留 D4+ 联调。

### 10.2 关键决策点 2：预支 + 清算（V1.2 §二.5.3 末尾）

```
季度前 2 月（M1 + M2）按 1.0 系数预支
  prepayAmount = baseAmount × 1.0 × 0.5（configs.performance.payout.prepay_rate = 0.5）

季度末（M3）按实际系数清算
  actualQuarterAmount = sum(每月 actualAmount)
  alreadyPaid = sum(预支月 prepayAmount)
  difference = actualQuarterAmount - alreadyPaid
  difference > 0：补差
  difference < 0：扣回（仅标记 + audit，实际扣款留 M4）
