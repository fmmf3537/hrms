## 4. 实施任务

### 4.1 子任务 1.1：考核周期（performance_cycles）

**表**：`performance_cycles`
- 字段：id (uuid) / code (string unique) / name (string) / type (enum) / startDate (date) / endDate (date) / status (enum) / description (text nullable) / createdBy (uuid FK) / createdAt / updatedAt
- enum：`type` ∈ {`monthly`, `quarterly`, `yearly`}；`status` ∈ {`draft`, `active`, `closed`}
- 状态机：`draft → active → closed`（单向，不可回退）
- index：`@@unique([code])` + `@@index([type, status])` + `@@index([startDate, endDate])`

**Service 函数**：
- `createPerformanceCycle(actorId, input)` — 创建周期（code 唯一 / 日期范围 / type 白名单）
- `listPerformanceCycles(actorId, filter)` — 列表（type/status/year 过滤 + 分页）
- `updatePerformanceCycle(actorId, id, input)` — 更新（仅 draft 可改 code；active/closed 只能 close）
- `closePerformanceCycle(actorId, id)` — 关闭周期（active → closed）

**Controller 函数**：
- `POST /cycles` → 调 createPerformanceCycle
- `GET /cycles` → 调 listPerformanceCycles
- `PATCH /cycles/:id` → 调 updatePerformanceCycle

**完整 schema + JSDoc + 错误码触发条件 + 测试断言**：见 §5.1。

### 4.2 子任务 1.2：指标库（performance_indicators）

**表**：`performance_indicators`
- 字段：id (uuid) / code (string unique) / name (string) / type (enum) / category (string nullable) / description (text nullable) / defaultWeight (decimal nullable) / target (text nullable) / unit (string nullable) / scoringRule (text nullable) / status (enum) / createdBy (uuid FK) / createdAt / updatedAt
- enum：`type` ∈ {`KPI`, `OKR`, `BSC`, `360`}；`status` ∈ {`active`, `archived`}
- index：`@@unique([code])` + `@@index([type, status])` + `@@index([category])`

**Service 函数**：
- `createPerformanceIndicator(actorId, input)` — 创建指标（code 唯一 / type 白名单 / weight 范围）
- `listPerformanceIndicators(actorId, filter)` — 列表（type/status/category 过滤 + 分页）
- `updatePerformanceIndicator(actorId, id, input)` — 更新（仅 active 可改；不能改 type/code）
- `archivePerformanceIndicator(actorId, id)` — 归档指标（active → archived）

**Controller 函数**：
- `POST /indicators` → 调 createPerformanceIndicator
- `GET /indicators` → 调 listPerformanceIndicators

**完整 schema + JSDoc + 错误码触发条件 + 测试断言**：见 §5.2。

### 4.3 子任务 1.3：考核方案（performance_schemes + 中间表）

**表 1**：`performance_schemes`
- 字段：id (uuid) / code (string unique) / name (string) / cycleId (uuid FK nullable) / applicableScope (enum) / applicableDeptId (uuid FK nullable) / applicablePositionLevel (string nullable) / status (enum) / description (text nullable) / version (int default 1) / sourceSchemeId (uuid FK nullable 自引用) / createdBy (uuid FK) / createdAt / updatedAt
- enum：`applicableScope` ∈ {`company`, `department`, `position`}；`status` ∈ {`draft`, `active`, `archived`}
- 当 `applicableScope = 'department'` 时 `applicableDeptId` 必填
- 当 `applicableScope = 'position'` 时 `applicablePositionLevel` 必填
- 当 `applicableScope = 'company'` 时 `applicableDeptId` / `applicablePositionLevel` 都为 null
- index：`@@unique([code])` + `@@index([cycleId, status])` + `@@index([applicableScope, applicableDeptId])` + `@@index([sourceSchemeId])`

**表 2**：`performance_scheme_indicators`（中间表）
- 字段：id (uuid) / schemeId (uuid FK cascade) / indicatorId (uuid FK) / weight (decimal) / target (text nullable) / sortOrder (int default 0) / createdAt / updatedAt
- 约束：同一 schemeId 下，weight 之和必须 = 100（提交时校验）
- index：`@@unique([schemeId, indicatorId])` + `@@index([schemeId, sortOrder])`

**Service 函数**：
- `createPerformanceScheme(actorId, input)` — 创建方案（含 N 个指标 + 权重）+ 校验权重和=100
- `listPerformanceSchemes(actorId, filter)` — 列表（cycleId/status/applicableScope 过滤 + 分页）
- `updatePerformanceScheme(actorId, id, input)` — 更新（仅 draft 可改；含指标可增删改权重）
- `clonePerformanceScheme(actorId, id, newCode, newName)` — 复制方案（含中间表 deep copy）

**Controller 函数**：
- `POST /schemes` → 调 createPerformanceScheme
- `GET /schemes` → 调 listPerformanceSchemes
- `POST /schemes/:id/clone` → 调 clonePerformanceScheme

**完整 schema + JSDoc + 错误码触发条件 + 测试断言**：见 §5.3。

### 4.4 子任务 1.4：等级系数（performance_coefficients）

**表**：`performance_coefficients`（沿用 V1.2 §四.7.2 设计）
- 字段：id (uuid) / grade (enum) / coefficient (decimal) / effectiveFrom (date) / effectiveTo (date nullable) / createdBy (uuid FK) / createdAt
- enum：`grade` ∈ {`S`, `A`, `B`, `C`, `D`}
- 同一 grade 同一时间只能有 1 个 effective 记录（effectiveTo=null）；新版本写入时旧版本 effectiveTo=新版本 effectiveFrom-1day
- index：`@@index([grade, effectiveFrom, effectiveTo])` + `@@index([grade, effectiveTo])`

**Service 函数**：
- `getActiveCoefficients()` — 获取当前生效的 5 档系数（effectiveTo=null 全部 grade）
- `updateCoefficients(actorId, input)` — 更新系数（写入新版本 + 关闭旧版本）
- `listCoefficientHistory(actorId, grade)` — 读某 grade 历史版本（按 effectiveFrom 倒序）

**Controller 函数**：
- `GET /coefficients` → 调 getActiveCoefficients
- `PATCH /coefficients` → 调 updateCoefficients
- 读历史不暴露端点（D3 内部用）

**完整 schema + JSDoc + 错误码触发条件 + 测试断言**：见 §5.4。
