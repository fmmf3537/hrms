### 步骤 1: Prisma schema 加 4 张表 + migration

在 server/prisma/schema.prisma 末尾追加：

```prisma
// ==================== AI 底座（M0.5-5）====================
// ai_documents（知识库文档）+ ai_embeddings（pgvector 向量）
// ai_conversations（对话历史）+ ai_summaries（AI 生成摘要缓存）

model AiDocument {
  id          String   @id @default(uuid()) @db.Uuid
  title       String   @db.VarChar(500)
  sourceType  String   @map("source_type") @db.VarChar(50) // employee_handbook / faq / policy / procedure
  content     String   @db.Text // 完整原文
  metadata    Json?    // 来源 URL / 版本号 / 维护人 等
  enabled     Boolean  @default(true)
  createdBy   String?  @map("created_by") @db.Uuid
  createdAt   DateTime @default(now()) @map("created_at") @db.Timestamptz(6)
  updatedAt   DateTime @updatedAt @map("updated_at") @db.Timestamptz(6)
  deletedAt   DateTime? @map("deleted_at") @db.Timestamptz(6)

  embeddings AiEmbedding[]

  @@index([sourceType, enabled])
  @@index([createdAt])
  @@map("ai_documents")
}

model AiEmbedding {
  id          String                      @id @default(uuid()) @db.Uuid
  documentId  String                      @map("document_id") @db.Uuid
  chunkIndex  Int                         @map("chunk_index") // 文档分块后的顺序
  chunkText   String                      @map("chunk_text") @db.Text
  embedding   Unsupported("vector(1536)")? // pgvector 维度（OpenAI text-embedding-3-small 1536 维）
  tokenCount  Int?                        @map("token_count")
  createdAt   DateTime                    @default(now()) @map("created_at") @db.Timestamptz(6)

  document AiDocument @relation(fields: [documentId], references: [id], onDelete: Cascade)

  @@index([documentId, chunkIndex])
  @@map("ai_embeddings")
}

model AiConversation {
  id          String   @id @default(uuid()) @db.Uuid
  userId      String   @map("user_id") @db.Uuid
  documentId  String?  @map("document_id") @db.Uuid // 命中的知识库文档（可空：闲聊）
  question    String   @db.Text
  answer      String   @db.Text
  sources     Json?    // 来源文档列表 [{title, score}]
  tokens      Int      @default(0)
  cost        Decimal  @default(0) @db.Decimal(10, 6) // USD 元
  duration    Int      @default(0) // 毫秒
  createdAt   DateTime @default(now()) @map("created_at") @db.Timestamptz(6)

  @@index([userId, createdAt])
  @@index([createdAt])
  @@map("ai_conversations")
}

model AiSummary {
  id          String   @id @default(uuid()) @db.Uuid
  type        String   @db.VarChar(50) // payroll_diff / performance_summary / contract_renewal
  referenceId String?  @map("reference_id") @db.Uuid // 关联业务记录 ID（工资单/绩效/合同）
  content     String   @db.Text
  highlights  Json?    // 高亮要点
  tokens      Int      @default(0)
  cost        Decimal  @default(0) @db.Decimal(10, 6)
  duration    Int      @default(0)
  expiresAt   DateTime? @map("expires_at") @db.Timestamptz(6) // 缓存过期
  createdAt   DateTime @default(now()) @map("created_at") @db.Timestamptz(6)

  @@index([type, referenceId])
  @@index([expiresAt])
  @@map("ai_summaries")
}
```

### 步骤 3: 创建 server/src/services/ai/ 目录，编写 service

创建以下文件：

#### 3.1 server/src/services/ai/embedding.service.ts
- 文档分块（按 chunk_size=500, overlap=50 字符切分）
- 调 LLM 拿 embedding 向量（通过 integrationService.send({ code: 'llm', payload: { type: 'embedding', input: chunks } })）
- 写入 ai_embeddings 表
- 检索：按查询 embedding 计算 cosine similarity，返回 topK
- 用 Prisma 的 $queryRaw 执行 pgvector 查询（`$queryRaw\`SELECT id, document_id, chunk_text, 1 - (embedding <=> $1::vector) AS similarity FROM ai_embeddings ORDER BY embedding <=> $1::vector LIMIT $2\``）
- 单测覆盖：分块 / 写入 / 检索

#### 3.2 server/src/services/ai/ocr.service.ts
- 调用 OcrAdapter（M0.5-5 在 server/src/integrations/adapters/ 新建 ocr.adapter.ts + map.adapter.ts）
- 返回结构化字段
- 写 audit（action='AI_OCR'）
- 错误码 6xxxx
- 单测覆盖：身份证 / 银行卡 / 证书 三种文档类型

#### 3.3 server/src/services/ai/qa.service.ts
- 入口：接收用户问题
- Step 1: embedding.service.search(question, topK=5) 检索相关文档
- Step 2: 拼装 prompt（system: 基于以下文档回答用户问题，user: question）
- Step 3: 调 LLM（integrationService.send({ code: 'llm', payload: { type: 'chat', messages } })）
- Step 4: 写 ai_conversations 表（含 userId, documentId, question, answer, sources, tokens, cost, duration）
- Step 5: 写 audit
- 单测覆盖：基本问答 / 无相关文档返回 fallback / token 统计

#### 3.4 server/src/services/ai/summarize.service.ts
- 入口：接收 type + referenceId + data
- 先查 ai_summaries 缓存（如果未过期）
- 缓存命中 → 直接返回
- 缓存未命中 → 调 LLM 生成摘要 → 写库
- 错误码 6xxxx
- 单测覆盖：缓存命中 / 未命中 / 过期

#### 3.5 server/src/services/ai/document.service.ts
- 知识库 CRUD：create / list / getById / delete
- 入库时自动：分块 + embedding + 写 ai_documents + ai_embeddings
- 单测覆盖：CRUD / 分块 / embedding 写入
