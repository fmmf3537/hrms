# HRMS 电子签成本评估

> **结论先行**：推荐 **e-签宝「SaaS 私有化版（轻量）」**，年成本约 **2400-3600 元**，覆盖 40 人 + 5 类合同所有签署场景
> **关联文档**：[`HRMS-V1.2.md`](./HRMS-V1.2.md) §二.2.4（合同管理）· §四.5（M1 A7 切片）

## 一、背景与决策

### 1.1 需求场景

- 员工规模：40 人（正式）+ 5-10 人（实习生/顾问/劳务）
- 合同类型：5 类（劳动合同 / 实习协议 / 顾问协议 / 劳务合同 / 保密协议）
- 签署频率：
  - 入职时签署：1 份/员工/年 → 约 50 份/年
  - 续签：每 2-3 年一次 → 约 20 份/年
  - 保密协议：入职 + 涉密岗位变更 → 约 50 份/年
  - 日常补充协议（调岗、薪酬变更等）→ 约 30 份/年
- **年度签署总量估算**：约 **150 份/年**（峰值约 200 份）
- 单份签署方数：2-3 方（员工 + 公司 + 见证方 HR）

### 1.2 决策

| 候选方案 | 推荐度 | 理由 |
|---|---|---|
| **e-签宝 SaaS 私有化版（轻量）** | ⭐⭐⭐⭐⭐ | API 集成成熟、签署单价低、本地化好、合同模板库丰富 |
| 法大大电子签 SaaS | ⭐⭐⭐ | 同样成熟，但起步价高于 e-签宝 |
| 上上签 | ⭐⭐ | 早期 SaaS，价格有竞争力但生态较弱 |
| 不接入电子签（继续纸质/扫描） | ⭐ | 增加 HR 80% 合同管理成本，**不推荐** |

## 三、3 年期成本预算

### 3.1 基础假设

- 员工增长：第 1 年 50 人 → 第 2 年 60 人 → 第 3 年 70 人
- 签署份数：人均 3 份/年（入职 1 + 续签 0.5 + 补充 1.5）
- 第 1 年：50 × 3 = **150 份**
- 第 2 年：60 × 3 = **180 份**
- 第 3 年：70 × 3 = **210 份**

### 3.2 成本对比表

| 套餐 | 第 1 年 | 第 2 年 | 第 3 年 | 3 年合计 |
|---|---|---|---|---|
| **e-签宝 SaaS 轻量** | 起步 3800 + 超出 50×35 = **5550** | 5800 + 80×30 = **8200** | 5800 + 110×28 = **8880** | **22,630** |
| **法大大 企业版** | 5800 + 0 = **5800** | 5800 + 0 = **5800** | 5800 + 10×50 = **6300** | **17,900** |
| **上上签 标准版** | 2800 + 50×32 = **4400** | 2800 + 80×30 = **5200** | 2800 + 110×28 = **5880** | **15,480** |

> **注**：实际超出单价各厂商商务谈判可下浮 20-30%，按面价估算保守

### 3.3 推荐方案：e-签宝 SaaS 轻量

**3 年总成本 22,630 元，年均 7,543 元**

理由：
1. **生态成熟**：阿里系背景，与钉钉/飞书/企微集成顺畅
2. **本地化最佳**：服务团队在西安有驻点（陕西子公司）
3. **签署单价低**：超出单价 28-35 元，3 年累计比法大大低（看具体谈判）
4. **合同模板库完整**：含劳动合同/保密协议国标模板
5. **API 集成案例多**：Node.js SDK 文档清晰，AI Coding 可参考

## 四、隐性成本与收益

### 4.1 隐性成本（不选电子签时）

| 项 | 成本估算 |
|---|---|
| HR 合同打印 + 邮寄 | 50 元/份 × 150 份 = 7500 元/年 |
| 员工通勤签署 | 半天工资 × 50 份 = 10000 元/年 |
| 合同扫描归档（专人） | 0.2 FTE × 8 万 = 16000 元/年 |
| 合同遗失/补办风险 | 难以量化但实际存在 |
| **年隐性成本合计** | **约 33,500 元** |

### 4.2 选电子签的收益

| 项 | 收益估算 |
|---|---|
| HR 合同管理时间 | 节省 60%（打印/邮寄/扫描/归档） |
| 签署周期 | 从平均 3 天 → 30 分钟 |
| 法律效力 | 与纸质同效，e-签宝已对接互联网法院 |
| 员工体验 | 不必亲自到场，远程完成 |

### 4.3 净收益估算（第 1 年）

- 选电子签：e-签宝 5550 元
- 不选电子签：隐性成本 33,500 元
- **净节省：27,950 元 / 年**

## 五、实施步骤（M1 A7 切片）

### 5.1 准备阶段（第 1 周）

- 注册 e-签宝企业账号
- 申请 API Key（企业认证 1-2 天）
- 下载 Node.js SDK 与 API 文档
- 测试环境联调

### 5.2 集成阶段（第 2-3 周）

- A7-1 Prisma model：contracts（已有，加 `e_sign_flow_id` / `e_sign_status` 字段）
- A7-2 合同模板上传到 e-签宝（HR 一次性操作）
- A7-3 service：`eSign.service.ts`（发起签署 / 查询状态 / 下载已签 PDF）
- A7-4 controller + routes：6 个 REST 接口
- A7-5 Vue 页面：合同列表 + 发起签署弹窗 + 签署状态查询

### 5.3 上线阶段（第 4 周）

- 灰度：HR 部门先试运行 1 个月
- 培训：HR（2 人）+ 员工自助签署指引
- 切换：所有新合同走电子签，老合同保留纸质

## 六、风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| e-签宝服务不可用 | 中 | 本地缓存签署 PDF 副本 + 异常报警 |
| API 升级导致集成失效 | 中 | 用 SDK 不用裸 API，跟随版本升级 |
| 合同法律效力争议 | 低 | e-签宝对接互联网法院，判例丰富 |
| 员工不熟悉电子签 | 低 | 引导视频 + HR 一对一辅导 |
| 数据跨境问题（北京平谷） | 低 | e-签宝数据存在国内，不涉及 |
