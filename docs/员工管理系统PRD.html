本文档是员工管理系统（HRMS）的产品需求文档，面向开发团队、测试团队及 HR 业务方，详细描述产品功能、交互规则、数据规则与边界条件，作为开发与验收的依据。

二、产品概述

2.1 产品定位

面向辰航卓越及下属子公司的一体化员工管理平台，覆盖"组织人事 + 考勤假勤 + 薪酬核算 + 绩效管理"四大核心模块，承载员工全生命周期数据，支撑公司 HR 数字化转型。

2.2 产品目标

  1. HR 事务性工作效率提升 ≥60%（减少手工算薪、手工考勤汇总）
  2. 薪酬核算差错率 ≤0.5%
  3. 员工入转调离流程线上化率 100%
  4. 绩效考核周期从 15 天缩短至 5 天

2.3 用户与角色

角色核心功能权限
系统管理员组织架构、用户/角色/权限、系数配置、流程配置、数据备份
HR员工档案、入转调离、合同、考勤汇总、薪酬核算、绩效汇总
部门负责人本部门员工查看、考勤审批、绩效评分与校准
高管全员报表、绩效终评、薪酬审批
正式员工打卡、请假/加班/出差申请、查看工资条、绩效自评
实习生/顾问/劳务打卡、查看劳务费结算单

2.4 系统边界

  • 包含：组织人事、考勤假勤、薪酬核算、绩效管理、劳务费结算
  • 不包含（一期）：招聘管理（已有系统）、培训管理、员工自助门户（二期）、AI 助手（三期）
  • 对接系统：现有招聘系统（二期）、短信平台、邮件服务、地图服务

四、详细功能需求

4.1 模块 A：组织人事

4.1.1 组织架构管理

功能描述：支持集团—法人—部门三级架构的可视化管理。

规则项规则说明
架构层级集团 → 法人（公司）→ 一级部门 → 二级部门（最多 4 级）
部门属性部门编码（唯一）、部门名称、上级部门、负责人、编制数、成本中心、生效日期
调整规则部门合并/撤销需 HR + 总经理双审批；调整历史保留 5 年
编制预警在岗数 > 编制数 × 1.1 时触发预警

4.1.2 员工档案管理

核心字段（共 8 类约 60 字段）：

类别关键字段必填敏感
基础信息工号、姓名、性别、身份证、出生日期、籍贯、民族是身份证加密
联系信息手机、邮箱、紧急联系人、现居住地手机必填否
教育经历学历、学位、毕业院校、专业、毕业时间最高学历必填否
工作经历历史雇主、岗位、任职时间否否
合同信息合同类型、签订/到期日期、续签记录是否
资质证书无人机执照、其他资质、有效期否否
银行卡开户行、卡号正式员工必填卡号加密
社保公积金参保地、基数、参保起止正式员工必填基数加密

关键交互：

  • 身份证号自动校验合法性，自动计算出生日期与性别
  • 合同到期前 30/15/7 天三级预警（系统消息 + 邮件）
  • 资质证书到期前 60 天预警（无人机执照年审）
  • 员工信息修改支持员工自助提交 + HR 审批（二期）

4.1.3 入转调离流程

入职流程：

  1. HR 发起入职登记（可对接招聘系统 offer 数据，二期）
  2. 系统自动生成工号（规则：法人代码 + 入职年份 + 4 位流水号）
  3. 收集资料清单（身份证、学历证书、银行卡、社保转移单、保密协议）
  4. 合同签订（电子签，一期线下扫描上传；二期电子签集成）
  5. 开通系统账号 + 分配角色
  6. 入职引导清单（设备发放、工位安排、导师分配、培训安排）

转正流程：

  • 试用期到期前 15 天自动触发提醒（HR + 部门负责人 + 员工）
  • 员工提交转正申请 + 上级评估 + HR 审批 + 总经理审批
  • 转正后薪资自动按正式薪资标准核算（从次月生效）

调动流程：

  • 调出部门负责人 + 调入部门负责人 + HR + 总经理逐级审批
  • 调动生效日自动更新：部门、岗位、汇报关系、薪酬标准、权限
  • 调动类型：平调 / 晋升 / 降职（晋升/降职需附带薪资变更审批）

离职流程：

  1. 员工提交离职申请（或公司发起）
  2. 工作交接清单（部门负责人确认）
  3. 设备归还 + 系统账号禁用 + 门禁权限回收
  4. 薪资结算（含未发工资 + 补偿金 + 调休折现）
  5. 社保减员 + 公积金封存
  6. 档案归档（保留 5 年）

4.1.4 合同管理

  • 合同模板库：劳动合同 / 实习协议 / 顾问协议 / 劳务合同 / 保密协议
  • 合同状态：草拟 / 待签 / 已签 / 即将到期 / 已到期 / 已终止
  • 合同附件：扫描件上传（PDF/JPG，单文件 ≤10MB）
  • 到期预警：30/15/7 天三级

4.2 模块 B：考勤假勤

4.2.1 打卡管理

打卡方式：

方式适用场景校验规则
WiFi 打卡固定办公（西安/北京/四川办公室）连接指定 WiFi SSID 才能打卡
GPS 打卡外勤/项目驻场定位精度 ≤100m，需上传位置描述
考勤机固定办公（可选）对接现有考勤机数据（一期手动导入）
补卡漏打卡每月限 3 次，需上级审批

打卡规则：

  • 标准工时：9:00-18:00，午休 12:00-13:30，弹性 30 分钟
  • 综合工时（生产/外场）：按月/季为周期综合计算工时
  • 不定时工时（高管/销售）：不打卡，仅记录出差/外勤
  • 迟到：9:00-9:30 打卡为迟到；>9:30 为缺卡
  • 早退：17:30 前打卡
  • 缺卡：当日无任何打卡记录

4.2.2 排班管理

  • 班次定义：班次名称、上下班时间、午休时长、有效日期
  • 排班粒度：按日 / 按周模板 / 按月模板
  • 排班冲突检测：连续工作 ≤6 天，最小休息间隔 ≥12 小时
  • 调班申请：员工发起 → 双方同意 → 上级审批

4.2.3 假勤管理

假期类型与额度：

假期类型额度规则薪资规则
年假工龄 1-10 年 5 天，10-20 年 10 天，>20 年 15 天带薪
病假按医疗期规定按当地最低工资 80% 计
事假不限无薪
调休加班 1:1 累计，有效期 6 个月带薪
婚假3 天 + 各地奖励婚假带薪
产假/陪产假按各地政策带薪
丧假1-3 天（直系亲属）带薪

请假审批流：

  • ≤3 天：员工 → 直属上级 → HR 备案
  • >3 天：员工 → 直属上级 → 部门负责人 → HR → 总经理
  • 年假/调休：系统自动校验余额，余额不足禁止提交

加班管理：

  • 加班申请：事前申请，注明加班事由与预计时长
  • 加班补偿：加班费（按法定标准）或调休（1:1），员工自选
  • 加班上限：每日 ≤3 小时，每月 ≤36 小时（劳动法）

出差管理：

  • 出差申请：出差地点、起止日期、出差事由、关联项目
  • 出差期间打卡：GPS 外勤打卡
  • 差旅补助：按出差天数 × 标准自动计算（按城市/职级差异化），进入薪酬模块

4.2.4 考勤汇总

  • 月度汇总：每月 1 日自动生成上月考勤报表
  • 员工确认：每月 3 日前员工在线确认，逾期默认确认
  • HR 锁定：每月 5 日 HR 锁定考勤数据，进入算薪流程
  • 考勤报表：出勤天数 / 迟到早退次数 / 请假时长 / 加班时长 / 出差天数

4.3 模块 C：薪酬核算

4.3.1 薪酬体系配置

薪级薪档：

  • 按岗位序列定义薪级表：高管（M1-M4）/ 部门负责人（M5-M6）/ 技术（T1-T6）/ 生产（P1-P6）/ 销售（S1-S6）/ 职能（A1-A6）
  • 每个薪级含 5-7 个薪档，对应基本工资 + 绩效工资基数

固浮比配置：

序列固定:浮动说明
高管60:40年薪制
部门负责人70:30月薪制
技术80:20月薪制
生产75:25月薪制
职能85:15月薪制
销售—底薪 + 回款提成

4.3.2 自动核算

月度核算公式：

应发工资 = 基本工资
        + 绩效工资（绩效工资基数 × 绩效系数）
        + 保密补贴（固定，按职级）
        + 勤补贴（按出勤天数 × 标准）
        + 项目奖金（按项目触发）
        + 销售提成（按回款金额 × 提成比例）
        + 年终奖（12 月单独发放）
        + 差旅补助（出差天数 × 标准）
        + 加班费（加班时长 × 加班费标准）

应扣款项 = 社保（个人部分）
        + 公积金（个人部分）
        + 个税（累计预扣）
        + 事假扣款（事假天数 × 日工资）
        + 病假扣款（病假天数 × 日工资 × 20%）
        + 迟到早退扣款（按次 × 标准）

实发工资 = 应发工资 - 应扣款项

核算触发：

  • 每月 5 日 HR 锁定考勤后自动触发核算
  • 核算异常自动提示（如绩效系数缺失、社保基数未配置）
  • 支持手动重算（需二次确认 + 操作日志）

4.3.3 社保公积金

多地方案：

城市养老保险医疗保险失业保险公积金
西安16% / 8%8% / 2%0.7% / 0.3%5%-12%
北京16% / 8%9.8% / 2%+30.5% / 0.5%5%-12%
四川16% / 8%8.5% / 2%0.6% / 0.4%5%-12%

注：单位比例 / 个人比例；比例为示例，实际按各地最新政策配置

  • 系统按员工参保地自动匹配方案
  • 每年 7 月支持批量调整基数（社保调基月）
  • 支持社保增减员台账导出（用于社保局申报）

4.3.4 个税

工资薪金（累计预扣法）：

  • 起征点：5000 元/月
  • 专项附加扣除：子女教育 2000/月、赡养老人 3000/月、房贷利息 1000/月、房租 1500/月、继续教育 400/月、大病医疗（年度 8 万限额）
  • 税率表：3% / 10% / 20% / 25% / 30% / 35% / 45%（7 级超额累进）

年终奖：单独计税或并入综合所得，员工自选（系统默认单独计税，12 月可切换）。

劳务报酬：

  • 预扣率：≤4000 元 800 元起征；>4000 元 20% 起征
  • 税率：20% / 30% / 40%（3 级超额累进）

4.3.5 劳务费结算（独立通道）

  • 适用对象：实习生 / 顾问 / 劳务人员
  • 结算方式：按次 / 按月 / 按项目
  • 计税：按劳务报酬所得
  • 发放：生成劳务费结算单，财务审批后发放
  • 凭证：自动生成记账凭证（借：管理费用-劳务费，贷：银行存款 / 应交税费-个税）

4.3.6 工资条与发放

  • 电子工资条：每月 10 日前推送（邮件 + 系统内查看）
  • 工资条内容：应发合计 / 各项扣款 / 实发金额 / 个税明细
  • 工资表导出：Excel / PDF（含汇总表 + 明细表）
  • 银行代发文件：工行 / 建行 / 招行格式
  • 薪酬审批流：HR 核算 → 财务复核 → 总经理审批 → 发放

4.4 模块 D：绩效管理

4.4.1 考核体系配置

考核模式：KPI + OKR 混合

  • KPI：定量指标（如销售额、项目交付率、bug 率）
  • OKR：定性目标（如"提升团队协作效率"）
  • 各序列指标类型统一框架：公司级指标 → 部门级指标 → 个人指标

考核周期：月度考核 + 季度兑现

考核等级与系数（后台可配置）：

等级系数（默认）比例建议说明
S1.5≤10%卓越
A1.2≤20%优秀
B1.0~50%合格
C0.8~15%待改进
D0.5≤5%不合格

注：头部限高不强制末位，比例仅供参考，季度校准会最终确认

4.4.2 考核流程

月度考核流程：

  1. 每月 25 日：员工提交自评（KPI 完成度 + OKR 进展）
  2. 每月 27 日：直属上级评分
  3. 每月 28 日：部门负责人校准
  4. 每月 29 日：HR 汇总
  5. 每月 30 日：总经理审批
  6. 次月 1 日：结果归档，绩效系数联动薪酬

季度校准会：

  • 每季度末月 30 日召开
  • 部门负责人 + HR + 总经理参加
  • 校准各部门 S/A/B/C/D 比例，避免过松或过紧

4.4.3 绩效兑现（双轨制，后台可切换）

模式一（默认）：系数直接乘绩效工资基数

绩效工资 = 绩效工资基数 × 绩效系数

模式二：部门绩效池二次分配

部门绩效池 = 部门绩效工资总额 × 部门绩效系数
个人绩效工资 = 部门绩效池 × (个人绩效系数 / 部门成员系数总和)

预支机制：

  • 季度前两个月按系数 1.0 预支
  • 季度末按实际系数清算（多退少补）

4.4.4 销售提成

提成规则：

  • 提成 = 回款金额 × 提成比例
  • 提成比例按产品/项目差异化配置（如无人机整机 5%、服务 8%、培训 3%）
  • 回款确认：财务确认到账后触发提成核算
  • 提成发放：随月度工资一并发放

销售目标：

  • 季度/年度回款目标
  • 新客户开发目标
  • 目标完成率与提成比例挂钩（如完成率 >120% 提成比例上浮 20%）

4.4.5 绩效结果应用

  • 调薪：年度调薪参考近 4 个季度绩效（S/A 优先）
  • 晋升：晋升答辩需提供近 2 年绩效记录（至少 2 个 A 或 1 个 S）
  • 淘汰：连续 2 个季度 D 档触发 PIP（绩效改进计划），PIP 期 3 个月，仍未达标启动离职流程
  • 培训：C/D 档员工自动纳入下季度培训计划

五、系统管理

5.1 用户权限

  • RBAC 模型：用户 → 角色 → 权限 → 资源
  • 数据权限：HR 全员可见；部门负责人本部门可见；员工仅本人可见
  • 敏感操作二次授权：查看薪资、导出工资表需部门负责人 + HR 双授权

5.2 审批流配置

  • 可视化流程设计器（拖拽配置）
  • 支持条件分支（如请假 >3 天自动加总经理审批）
  • 支持会签 / 或签 / 依次审批
  • 支持审批超时自动提醒（24 小时未审批提醒，48 小时升级）

5.3 系数配置

  • 绩效系数：S/A/B/C/D 五档系数可调整
  • 固浮比：按序列可调整
  • 提成比例：按产品/项目可调整
  • 差旅补助标准：按城市/职级可调整
  • 所有调整留痕，支持版本回溯

5.4 数据字典

  • 学历、民族、政治面貌、婚姻状况、假期类型、合同类型等基础数据维护
  • 支持自定义扩展字段

5.5 审计日志

  • 记录所有关键操作：登录、查看、新增、修改、删除、导出、审批
  • 日志字段：操作人、操作时间、操作类型、操作对象、操作前后值、IP 地址
  • 日志保留 3 年，支持按人/按时间/按操作类型检索

八、非功能需求

8.1 性能指标

  • 并发用户：≥100
  • 核心页面响应：<2s
  • 月度算薪：200 人 <30s
  • 报表导出：<10s
  • 数据库查询：P95 <500ms

8.2 安全要求

  • 认证：JWT + Refresh Token + 二次验证（短信/邮箱）
  • 加密：敏感字段 AES-256；传输 HTTPS
  • 权限：RBAC + 数据权限 + 敏感操作二次授权
  • 审计：全量操作日志，保留 3 年
  • 备份：每日全量 + 每小时增量，保留 30 天

8.3 合规要求

  • 《个人信息保护法》《数据安全法》《劳动法》
  • 公司保密资质审查要求

九、UI/UX 设计要求

9.1 设计原则

  • 简洁高效：HR 高频操作 ≤3 步完成
  • 信息分层：核心信息一屏展示，次要信息折叠
  • 移动端优先：打卡/请假/审批等高频操作移动端友好
  • 一致性：与现有招聘系统保持 UI 风格一致（Element Plus）

9.2 关键页面

  • 工作台（待办、快捷入口、数据看板）
  • 组织架构（树形 + 列表双视图）
  • 员工档案（分组表单 + 附件管理）
  • 考勤日历（月度视图 + 异常标记）
  • 工资条（卡片式 + 明细展开）
  • 绩效评分（指标列表 + 滑块评分）
  • 审批中心（待办/已办/我发起）

十、埋点与数据指标

10.1 关键指标

  • HR 事务性工作时长（月度）
  • 薪酬核算差错率
  • 考勤异常处理时长
  • 绩效考核周期时长
  • 员工自助服务使用率（二期）

10.2 埋点事件

  • 页面访问（PV/UV）
  • 关键操作（打卡、请假、审批、算薪、导出）
  • 异常事件（打卡失败、算薪异常、审批超时）

十一、上线计划

11.1 里程碑

阶段时间交付物
需求确认第 1 周本文档 + 需求文档终稿
原型设计第 2-3 周关键页面原型
开发（迭代 1）第 4-7 周组织人事 + 考勤假勤
开发（迭代 2）第 8-11 周薪酬核算 + 绩效管理
联调测试第 12-13 周系统联调 + 用户验收测试
数据迁移第 14 周40 名员工档案迁移
试运行第 15-16 周并行手工核算，验证系统准确性
正式上线第 17 周系统切换，手工核算停止

11.2 验收标准

  • 功能验收：所有功能点按本文档验收
  • 性能验收：100 并发压测通过
  • 数据验收：与手工核算并行 2 个月，差错率 ≤0.5%
  • 安全验收：渗透测试无高危漏洞

十二、风险与应对

风险等级应对
AI Coding 生成代码质量不稳定高严格代码评审 + 完整测试用例 + 小步迭代
薪酬核算规则复杂易错高核算规则测试用例库 + 与手工核算并行 2-3 个月
多地社保政策频繁调整中社保方案配置化 + 季度政策复核
员工抵触新系统中充分培训 + HR 一对一辅导
数据迁移错误中迁移脚本双跑校验 + 历史数据备份
